# Archetype: `firefox-extension` (WebExtensions / `.xpi`)

Load when `admin.toml` has `archetypes = [… "firefox-extension" …]`. `dev` runs
the extension in a temporary Firefox profile; `build`/`package` produces the
`.xpi`.

No archetype-specific gotchas documented yet — add them here as they're found.
Defer to the main SKILL.md for general workflow.
