How does one fragment become a whole explainer?

Assuming you know what an HTML file and a build script are, but have never opened tool/explain — tell me if I'm off.

The short version: you write one file of real content, the tool glues a stylesheet and a symbol cast around it, and what comes out never makes a network request.

Step 1

You write a body fragment — content only, no page scaffolding.

tool/explain:44

A <!doctype>, <html>, <head>, or <body> tag in the fragment is refused before anything is written — the tool owns those.

Step 2

The tool checks it for a network request and refuses if it finds one.

tool/explain:60-75

A hermetic explainer opens the same on a plane as it does on a conference wifi. There is no exception for "just one small icon font".

Step 3

It wraps your content in one stylesheet and one symbol cast.

tool/explain:78-101

Neither the CSS nor the fourteen symbol definitions ever enter the model's context — they live on disk in tool/assets/ and get concatenated in at build time.

The code 
# tool/explain:78-84
base_css = read(os.path.join(ASSETS_DIR, "base.css"))
symbols  = read(os.path.join(ASSETS_DIR, "symbols.html"))

The part that surprises people

There is no theme toggle and no dark mode. This kind is light-only by design — the bright textbook look is the point, not a default waiting for a switch.
