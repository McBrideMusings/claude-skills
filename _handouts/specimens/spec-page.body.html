Handout store: what the five kinds cost to maintain

1,285 lines of CSS across ten files, four of which no skill has ever edited. This is where that weight sits and which parts are load-bearing.

Where the lines are

The harness outweighs the kinds two to one. annotate.css alone is larger than every kind stylesheet put together, which is the shape you would expect from a review layer that has to survive being dropped onto arbitrary markup.

The three that carry the look

_base.css sets every token the other nine consume: the type scale, the spacing scale, the neutral ground and the single accent. Change a value there and all five kinds move together — which is the point, and also the risk.

explainer.css is the only kind with a fixed palette, because in an explainer hue carries meaning. page.css is deliberately near-empty so each page can choose its own identity.

Neither page.css nor deck.css has ever been given a real type pairing; both inherit the system sans for headings and body alike.

What this costs

Nothing at runtime — the tool inlines the stylesheet at assembly time, so none of it is ever read into a model's context. The cost is entirely in drift: ten files, one shared token set, and no specimen that renders all of them at once.
