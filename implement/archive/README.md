# Archived

These files ran the `implement` pass as a `Workflow` script: five stage agents — Plan, Implement, Review, Verify, Wrap — each with its own cold context, plus an in-script fix loop of up to three rounds.

They are kept for reference and are **not a way to run a pass.** Nothing loads them, nothing calls them, and a pass is never dispatched this way. [`../SKILL.md`](../SKILL.md) is the live method.
